# 📘 DSA with C++ (Arrays Focus)

This repository contains **Data Structures and Algorithms (DSA)** programs
implemented in **C++**, with a primary focus on **Arrays** and basic STL usage.


---

## 📌 Topics Covered

### 🔹 Arrays
- Array creation and traversal
- Insertion and deletion
- Searching (Linear, Binary)
- Sorting (Bubble, Selection, etc.)
- Maximum & minimum element
- Sum, average, reverse array
- Duplicate elements
- Frequency counting

### 🔹 STL Basics
- vector
- array
- basic input/output handling

---

## 🛠 Technologies Used
- Language: **C++**
- Compiler: GCC / g++
- IDE: VS Code / Any C++ IDE

## 🎯 Purpose
- Academic practice (B.Tech CSE)
- Strong DSA foundation
- Interview preparation
- Clean and beginner-friendly code
- Start with easy problem solving.
